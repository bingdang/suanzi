极简网页计数器

两行代码搞定计数，永久免费使用。

快速开始：
<script async src="//suanzi.cakepanit.com/js/busuanzi.min.js"></script> <span id="busuanzi_container_site_pv">本站总访问量<span id="busuanzi_value_site_pv"></span>次</span>
支持的计数类型：
站点总访问量 (site_pv) - 统计整个网站的页面浏览量
站点总访客数 (site_uv) - 统计整个网站的独立访客数
单页面阅读量 (page_pv) - 统计当前页面的浏览量
使用示例：
<!-- 站点总访问量 --> <span id="busuanzi_container_site_pv">本站总访问量<span id="busuanzi_value_site_pv"></span>次</span> <!-- 站点总访客数 --> <span id="busuanzi_container_site_uv">本站访客数<span id="busuanzi_value_site_uv"></span>人次</span> <!-- 单页面阅读量 --> <span id="busuanzi_container_page_pv">本文阅读量<span id="busuanzi_value_page_pv"></span>次</span>

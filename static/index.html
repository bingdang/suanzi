UV 识别

UUID + Cookie

工作流程

  1. 页面加载时，JS 脚本自动生成/读取用户 UUID（存 Cookie，有效期 1 年）
  2. 调用 POST /api/count 接口，上报 PV/UV 数据
  3. 后端查询数据库，返回计数值
  4. 前端将计数值回填到对应的 span 标签

API 接口

# 首页或普通页面（统计站点访问）
POST /api/count
Body: {
  "domain": "example.com",
  "uuid": "xxx-xxx-xxx",
  "types": ["site_pv", "site_uv"]
}
Response: {
  "counts": {
    "site_pv": 1234,
    "site_uv": 567
  }
}

# 文章页或详情页（统计页面阅读）
POST /api/count
Body: {
  "domain": "example.com",
  "uuid": "xxx-xxx-xxx",
  "path": "/article/123",
  "types": ["page_pv"]
}
Response: {
  "counts": {
    "page_pv": 89
  }
}
# 💡 提示：请求 page_pv 时会自动同时增加 site_pv

📌 说明

  • UUID 生成：首次访问时自动生成 UUID 并存入 Cookie（有效期 1 年），后续访问自动读取
  • UV 去重：同一用户（相同 UUID）每天只计 1 次 UV，刷新页面不会重复计算
  • PV 计数：每次页面加载都会增加 PV，刷新会累加
  • 自动联动：请求 page_pv 时后端会自动同时增加 site_pv，无需重复请求
  • Referer 校验：请求的 Referer 域名必须与 domain 参数一致，防止恶意刷量
